# NLP From Scratch

A beginner-friendly Natural Language Processing project built
to understand fundamental NLP concepts before using high-level
NLP libraries.

## Project Goals

The goal of this project is to understand how basic NLP
techniques work internally.

## Concepts Implemented

- Tokenization
- Stopword Removal
- Stemming
- Bag of Words
- TF-IDF
- Naive Bayes Classification
- Accuracy calculation
